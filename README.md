# Global Solar

Complete static website in Serbian Latin, ready to serve from the repository root.

## Files

- `index.html`: website content and search metadata
- `style.css`: responsive styling
- `app.js`: mobile navigation
- `assets/`: logo and optimized WebP images
- `robots.txt`, `sitemap.xml`: search crawler files
- `.nojekyll`: serve static files unchanged on GitHub Pages

No installation or build step is required. Publish the repository root with GitHub Pages, Cloudflare Pages, or another static host.

Search metadata targets `https://globalsolar.online/`. Connect that domain in your hosting settings and DNS before launch; uploading this repository does not configure hosting or DNS.
